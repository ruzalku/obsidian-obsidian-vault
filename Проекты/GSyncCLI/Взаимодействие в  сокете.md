
## Работа с ответами главного демона

Передача через пайплан в виде:
```flag text```

flag - bool (если 0, то ошибка, если 1 то нет)
text - string (текст ошибки (если есть))


## Работа с запросами на главный демон

### Сохранение файлов

```save path autosave```

path - string (путь до файла)
autosave - bool (флаг на автосохранение (1 - да, 0 - нет))

## Формат json-файла для реестра файлов

  

```json

[

	{

		"id": "fid in Google Drive",

		"path": "path to file",

		"hash": "hash of file",

		"lastSave": "time of last saving",

		"autosave: false (autosaving flag)

	},

	...

]

```
